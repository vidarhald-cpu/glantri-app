# Competency reference

This reference brings the approved Skill, Learning Group, and Profession
catalogues together without changing their content.

- [Competency rules](../competency-rules.md)
- [Skills](./skills.md)
- [Learning Groups](./learning-groups.md)
- [Professions](./professions.md)
- [Societies and availability](./societies.md)
- [Availability gaps and exceptions](./gaps-and-exceptions.md)
- [Reference manifest](./reference-manifest.json) for deterministic inventory
  and source-digest verification

The cross-links are derived from the same approved catalogues used by Glantri:

- 131 base Skills and 26 Specializations;
- 59 Learning Groups with 151 base-Skill and 9 explicit Specialization
  memberships;
- 84 Profession families with 115 Learning Group and 88 direct competency
  opportunities;
- 21 explicit Profession tracks.

The [Societies and availability](./societies.md) page records the six Society
Levels, four Social Bands, eleven current Arch-Society lenses, and contextual
binding rules without inventing the unfinished society content.

Spoken languages and Written Traditions remain separate contextual
competencies. None has a generic Learning Group membership or an exact generic
Profession binding. They are therefore discussed in the availability report
rather than being presented as base Skills.

The ordinary entries use game-facing names. Source identities, extraction
digests, reconciliation history, and audit evidence remain in the source and
architecture documents linked from the [gaps and exceptions
report](./gaps-and-exceptions.md).

Availability statements are deliberately conservative. “General/unbound”
means the entry is valid in the generic reference; it does not assert that a
particular Setting, Society Level, Social Band, Arch Society, institution, or
teacher supplies the route.
